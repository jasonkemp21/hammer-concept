Hammer Fitness and Boxing: website concept (static site)

Upload the contents of this folder (index.html and the img folder) to any static host:
Netlify, Cloudflare Pages, Vercel, GitHub Pages, or your own web server. No build step.

Notes
- Host it on a domain or subdomain you own. Do not use the gym's domain or a lookalike of it.
- index.html carries a noindex tag so search engines skip it.
- Keep the "Concept" bar. Bookings, checkout and forms are simulated.
- Fonts load from Google Fonts, so the page needs an internet connection to look right.
